# booklib 設計メモ

町の小さな図書室で使う、蔵書と貸出の管理ライブラリです。サーバーは立てず、Python のライブラリとして使います。

## データ

- 蔵書（`Book`）: 蔵書 ID・書名・著者・ISBN・出版年・タグ
- 利用者（`Member`）: 利用者 ID・名前
- 貸出（`Loan`）: 蔵書 ID・利用者 ID・貸出日・返却期限・返却日

蔵書は `data/books.csv` から読み込みます（`catalog.load_catalog`）。タグは `;` で区切ります。

## 貸出の決まり

- 貸出の期間は **14日** です（`loans.LOAN_DAYS`）。返却期限は貸出日の14日後です
- 返却期限を過ぎても返されていない貸出を「延滞」と呼びます（`LoanService.overdue`）
- 同じ本を同時に2人へ貸すことはできません。貸出中の本の貸出は断ります
- 存在しない蔵書 ID の貸出は断ります

## 検索

- 大文字・小文字を区別せず、書名の部分一致で探す（`Catalog.find_by_title`）
- 書名・著者・タグのどれかにキーワードを含む本を探す（`Catalog.search`）

## コードの決まり

- 関数には型ヒントを付けます
- 日付は `datetime.date` で持ち、文字列にするときは `2024-01-05` の形にします
